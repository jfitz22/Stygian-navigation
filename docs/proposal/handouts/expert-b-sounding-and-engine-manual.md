## Page 6: The Linesman's Board

```
┌────────────────────────────────────────────────────────────────────┐
│ ASK THE OPERATOR FOR:  station name · CAUSE icon (claw, jaw,       │
│   swarm) · for each conduit: sheath, frost, star tag, far lamp     │
├────────────────────────────────────────────────────────────────────┤
│ Take each conduit in turn, top to bottom. FIRST rule that fits:    │
│                                                                    │
│  ① Far lamp DARK and sheath PORCELAIN ................ CUT         │
│  ② FROSTED and STAR ................................... BYPASS     │
│       ...but if the cause is the JAW ................. SHUT         │
│  ③ IRON and NOT frosted ............................... OPEN        │
│  ④ BRASS:  shelf post (Gallowmere, Hookspur) ......... OPEN        │
│            sea post or buoy ........................... SHUT        │
│  ⑤ Anything else ...................................... SHUT        │
│                                                                    │
│ When all six are set, the Operator pulls DISPATCH.                 │
│ A spark means one conduit is wrong. Only that one resets.          │
│                                                                    │
│ ✱ Never send a sled while the beast is still at the station.       │
│   The damage lamp turns from red to amber when it has gone.        │
└────────────────────────────────────────────────────────────────────┘
```

## Page 9 (excerpt): Things in the Water

```
┌────────────────────────────────────────────────────────────────────┐
│ THE GRINDMAW. A broad, low band that walks across the Hearkener.   │
│   It follows noise: two soundings from one buoy within a minute    │
│   are enough. It eats buoys that are in the water. A reeled buoy   │
│   is safe. A sounding elsewhere may draw it away.                  │
│                                                                    │
│ BURROWERS (remorhazes). Watch each post's GROUND needle. They hunt │
│   heat. A post below the second mark on its thermometer is beneath │
│   their notice.                                                    │
│                                                                    │
│ HEARTBEATS. A slow ripple on an echo, a pulse on the Hearkener.    │
│   What lives in the ice defends its young.                         │
└────────────────────────────────────────────────────────────────────┘
```
