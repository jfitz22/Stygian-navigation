# The Last Watch: running list

What we want to add next, roughly in priority order. Revision 3 is the main game (2026-10-02).

## Core loop: find → investigate → rule out
- **Case board** (split-flap style, lower half of the repair bay). Locking ice gives it a row: number, current square, and cells for ECHO, METAL and RADIO. Instruments write their *raw* readings into the cells automatically ("3 bumps, ringing", "METAL FOUND", "612.4 STEPPED W-R-B"); the crew still decodes them and flips a verdict (unknown / suspect / excluded). Clicking a row re-locks that ice. Split-flap clack as cells fill; a satisfying stamp on EXCLUDED.
- **A clean three-step funnel: echo → metal → radio.** Elgarz is the only ice that is hollow, metal *and* sings the Triad. Each step should cut the field noticeably.
- **Gilded Hulk gets a failing sign** (e.g. Triad in the wrong band) so the three active tests always identify Elgarz. Keep its pull toward the Tomb as a bonus tell for sharp crews.
- **Tomb demoted to a search hint and lore**: "Elgarz never comes within 300 mi of the Tomb". No case-board column.
- **Probes** (still to decide): red = radio relay, orange = metal sensor, blue = ? (drift-log/tracking idea parked along with the Tomb test). Radio and scanner keep working on buoy-pinged ice too; probes are an extra route, never a replacement. Possibly towers fire only one probe type.

## Onboarding and atmosphere
- **Guided warm-up** in the first three minutes (Elgarz isn't in the sea yet): a "first watch checklist" on the wire service (light the furnace, drop a buoy, ping, lock something).
- **Dismissible handouts** on screen at the start: old scrawled notes left by the previous watch, each hinting at a system.
- **Ending beat**: after the blue light, an epilogue/debrief card (time, green beacons used, ice examined, rule-outs).
- **Rising pressure** after ~12 minutes (storms and the Grindmaw escalate) so the end of the watch feels urgent; still nothing ends the game early.
